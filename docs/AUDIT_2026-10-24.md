## Проблемы по важности

**Высокие**
1. **Нет авторизации на API** (`api/main.py`): любой, кто достучался до порта, может `DELETE /portfolios/{id}`, `POST /cache/clear`, писать/перезаписывать портфели. Compose публикует `8000:8000` и `3000:3000` на **0.0.0.0** (LAN). Фикс: `127.0.0.1:8000:8000` в compose для локального режима; для публичного — auth/reverse proxy.
2. **Next.js 15.3.3 — critical CVE** (+ postcss/sharp/nanoid/source-map-js high). Фикс: обновить `next` до исправленной версии, `npm audit fix`, пересобрать.
3. **Всё новое не в git**: `api/`, `frontend/`, `src/services/`, Docker-файлы, `src/portfolio_templates.py` — риск потери работы. Нужен коммит (на ваше решение).

**Средние**
4. CORS: `allow_origins=["*"]` + `allow_credentials=True` (`api/main.py:51-56`) — отражает любой Origin с credentials (подтверждено: `Origin: http://evil.example` отражён). Фикс: список origin из env.
5. Нет лимита размера загрузки CSV (`/portfolios/preview-csv`, `/import-csv`): 3 МБ принято без ограничений; DoS по памяти. Фикс: лимит размера.
6. Path traversal на Windows-хосте: `portfolio_id` попадает в `storage_dir / filename` без санации (`src/utils/data_fetcher.py:1285-1300, 1382-1395`; DELETE добавляет `.json`). В Docker (Linux) `..\` безвредно (проверено: 404), при нативном запуске на Windows — теоретически возможен выход из каталога. Фикс: `Path(filename).name` + проверка resolve внутри `storage_dir`.
7. Контейнеры работают от root (оба Dockerfile, `id -u` = 0).
8. Утечка абсолютного серверного пути в тексте 404 (`/app/src/data/portfolios/...`).
9. `POST /optimization/run` с несуществующим `portfolio_id` → **500** вместо 404 (`api/main.py` ~ `optimization_run`: `load_portfolio` не обёрнут в try).

**Низкие**
10. `/docs` и `/openapi.json` открыты; нет security-заголовков, `X-Powered-By: Next.js`; rate-limit нет.
11. `CASH` строка автоматически добавляется в тикеры и попадает в оптимизацию (вес 10% на CASH в тесте) — проверить, задумано ли.
12. Зависимости `>=` без lock-файла (Python) — невоспроизводимые сборки; `requirements.txt` содержит транзитивные пакеты (altair, gitpython, …).
13. `use_container_width` в Streamlit deprecated (после 2025-12-31); дубль `run.py`/`run_app.py`; `LICENSE` и `LICENSE.txt`; README: «private use only» vs MIT-подобный LICENSE.
